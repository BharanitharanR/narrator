# narrator

An Agent Skill for turning video understanding into timestamped AI voiceover scripts.

Narrator consumes [video-analysis](https://github.com/BharanitharanR/video-analysis) output. The analyser identifies the video type; narrator decides whether to narrate and uses the semantic timeline (and `screen_actions`, when present) to create evidence-grounded narration.

Pipeline: video -> video-analysis -> analysis.json -> narrator plan -> narration-plan.json -> narrator voice -> voiceover.wav -> goldilock-av-mixer -> final.mp4.

Narration is explanatory, not speculative. Each claim should be traceable to timestamped observations.

## Install

```bash
python3 -m venv .venv
.venv/bin/pip install -e '.[dev,gemini]'
```

## Use

```bash
narrator decide analysis.json
narrator plan analysis.json -o narration-plan.json --notes "Product: Acme Desk; audience: support agents"
narrator plan analysis.json -o narration-plan.json --mode dialogue --speakers "Maya:curious host,Arun:guide" --voices Puck,Kore
narrator plan analysis.json -o narration-plan.json --speech-segments speech.json
```

- `decide` prints the narrate-or-not decision without calling Gemini. Narration is planned for demo, tutorial, walkthrough, presentation, documentation, screen_recording and review with confidence at least 0.6. `--force` or an explicit `--mode` overrides a "no".
- `plan` writes a NarrationPlan 1.1. When the decision is "no", it writes a plan with `decision.narrate=false` and no segments, and makes no Gemini call. When it calls Gemini, it also writes `narration-request.json` and `narration-response.raw.json` next to the plan.
- Modes: `single` (voice `Kore`) or `dialogue` (host `Puck`, guide `Kore`).
- `--speech-segments` takes `speech.json` from `goldilock-av-mixer detect-speech`; those spans become `original_speech` no-voice windows.
- After Gemini returns, code recomputes `estimated_speech_seconds` and `fit_status` and flags overlaps in `review_notes`.

Gemini model fallback: `--model` first, then `NARRATOR_MODELS` (comma-separated) or the default chain. `NARRATOR_MAX_MODEL_ATTEMPTS` (default 3) caps the attempts; `NARRATOR_MODEL_FALLBACK=0` disables fallback. Requires `GEMINI_API_KEY`.

See `SKILL.md` for the full workflow, `references/narration-plan.schema.json` (generated by `scripts/generate_schema.py`) and `examples/`.
